# Project instructions — meeting-transcriber

## Default output location for Claude-created files

When creating a new file in this repo, write it to `outputs/` by default —
unless one of these applies:

- The file is generated by the `/meeting-notes` skill — that goes to `notes/`
  (existing convention, unchanged).
- The user explicitly names a different location for the file (path, folder,
  or "put it in X").
- The file is core app code that belongs at repo root by convention:
  `transcribe.py`, `test_audio.py`, `audio_route.swift`, `README.md`,
  `LICENSE`, `.gitignore`.
- The file belongs in an existing structural folder by its nature — e.g. a
  plan file goes in `.claude/plans/`, a doc explaining the app goes in
  `docs/`, not `outputs/`.

This does not apply to files the *app* writes at runtime (e.g.
`transcribe.py` writing to `transcripts/`) — only to files Claude itself
creates during a session (reports, scratch scripts, diagrams, decks,
one-off docs, etc.).

If ambiguous which bucket a new file belongs in, ask rather than guess.
